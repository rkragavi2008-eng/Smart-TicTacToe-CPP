#  Tic Tac Toe Game in C++

##  Description
This is a simple console-based Tic Tac Toe game developed using C++.

It is written in Notepad and compiled using a C++ compiler.

---

##  Features
- 3x3 Tic Tac Toe board
- Player vs Player mode
- Player vs Computer mode (basic)
- Win detection
- Draw detection
- Replay option

---

##  Concepts Used
- Arrays
- Loops
- Conditional statements
- Functions

---

##  How to Compile and Run

### Step 1: Compile
g++ game.cpp -o tictactoe

### Step 2: Run
tictactoe
